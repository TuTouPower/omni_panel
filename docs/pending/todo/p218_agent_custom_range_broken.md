# p218 代理面板自定义日期三故障：下拉打不开、应用无生效、面板被环图盖住

- 现象：web 版代理面板时间范围「自定义」三处异常（用户报 web 版、首次选自定义即无效）。① 下拉选自定义无效果：时间范围下拉选「自定义」后无面板弹出，下拉值弹回预设（如 30d），必须点后方「📅 自定义」按钮才弹面板。复现：`.scratch/bug_custom_range/repro_a.test.tsx`（userEvent.selectOptions 真实序列失败；同文件 fireEvent.change 对照通过）。② 自定义区间应用无生效：设好起止点应用后查询未按所选区间走。两条已验证路径：B1 非法区间（结束\<=开始/空）点应用静默丢弃且面板照常关闭（`repro_b1`）；B2 编辑中途 web 10s 轮询 `onUpdated(0)` 经 `preset_range_revision` 改写 `currentRange`，`RangePicker useEffect[start,end]` 把用户输入重置回预设区间，应用带走的是预设区间（`repro_b2`：输入 `2026-06-01T08:00` 被改写为当时预设区间）。③ 自定义日期面板被下方环形图盖住：`RangePicker` 弹出层 `z-menu` 类在构建产物中无对应规则，`z-index:auto` 按 DOM 先后被 donut/ECharts 区覆盖。
- 影响：自定义时间范围入口基本不可用（下拉入口死、按钮入口遇 B1/B2 丢区间、面板被盖住难操作）。同类并集：裸 `z-*` 层级类同样无规则的三处（回到底按钮 `SessionPane.tsx:337 z-sticky`、会话大纲面板 `SessionPane.tsx:346 z-context`、资源坞 `SelectionDock.tsx:25 z-sticky`），视觉影响各点待修复 task 逐点验证；`Toast/Dialog/WorkspaceToolbar/SessionPreview` 用 `z-[var(--z-*)]` 已验有规则，不受影响。
- 根因：产品缺陷，三机制同属「时间范围自定义链路」合并一条。A：`TokenStatsView.tsx:748-755` Select 受控值在 custom 未落盘前仍为预设，`RangePicker.tsx:51-66` document click-to-close 与下拉开启手势未协调——选择手势的尾随 click 落到 document（Select 在 wrapRef 外、无 stopPropagation）把刚打开的面板瞬间关掉；附带同因：custom 已生效后重选 custom 无 change 事件（原生 select 同值不触发），下拉无法二次打开。B1：`RangePicker.tsx:68-74,124-133` 校验失败静默返回而关闭无条件，零反馈。B2：`TokenStatsView.tsx:251-265` 预设分支 revision 机制与 `RangePicker.tsx:46-49` 无条件回填输入耦合，后台刷新丢弃编辑中状态。C：`RangePicker.tsx:96 z-menu` 引用的工具类不存在——Tailwind v4 `--z-*` 不生成裸 `z-*` 工具类，构建 CSS 实测 `.z-menu/.z-sticky/.z-scrim/.z-context/.z-modal` 零规则（仅 `z-[var(--z-*)]` 任意值有效）；`DESIGN.md:434`「映射为工具类」断言为假，t415 据此前提迁移。分类：产品缺陷（含测试假绿，见测试缺口）。已确认位点清单：`TokenStatsView.tsx:744-774`、`RangePicker.tsx:46-66,68-74,94-96`、`SessionPane.tsx:337,346`、`SelectionDock.tsx:25`、`DESIGN.md:434`（文档前提）。附带发现（非本次主诉、修复 task 定夺是否同批）：custom 不持久化——`save_prefs` 存 `preset:null` 但 `load_prefs` 侧 `saved.preset ?? "30d"` 回退且 `custom` 永不恢复，刷新即丢自定义。
- 测试缺口：① `token_stats_header.test.tsx` 自定义用例用 `fireEvent.change`（无尾随 click）打开面板，绕过真实手势序列，生产手势失败而测试绿——假绿；且只断言 `start<end` 弱条件，从未键入真实自定义日期做端到端断言。② `RangePicker.test.tsx` 只覆盖按钮打开+合法应用，无非法输入、无受控开关、无外部刷新用例。③ 无 web 轮询中途编辑用例（B2 只在 live 数据/10s 轮询下触发，单测无 onUpdated 交织）。④ designmd/t415 门禁只做负向检查（裸数字清零）与变量发射检查，从不验证 `z-*` 类真实生成——需补构建产物正向断言。补测方向：下拉 custom 用 userEvent 全序列断言面板保持打开；custom 生效后重选 custom 可重开；键入起止→应用→`getDashboard` 收到精确起止；非法区间应用给出行内错误且面板不关；编辑中途 `fire_updated(0)` 后输入保留、应用仍带用户日期；构建产物（或单测扫描）断言各浮层 z 类有规则。
