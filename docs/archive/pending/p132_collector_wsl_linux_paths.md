# p132 collector 采集路径硬编码 Windows 宿主,Linux/WSL 运行全源采集失效

- 现象：代理面板(TokenStatsView)缺 8.09 部分、8.10 与 8.11 用量数据。期望本机用量自动采入。实际 records/daily 最新到 2026-08-09 05:36,其后采集持续 0;8-11 软件运行中仍无新数据,而本机 `~/.claude/projects/**`、`~/.kimi-code/sessions`、`~/.grok/sessions` 存在大量 8-11 用量 jsonl。
- 影响：在 Linux/macOS/WSL 环境运行 OmniPanel 时,token-stats 采集(代理面板、24h 图表、热力图、会话表)全量不可用且无任何可见告警。已确认同类位点(机制同源、修复须一并覆盖):① `collector.ts` 全部 path builder(claude/opencode/kimi/grok)+ `effective_wsl_user`(主位点);② `index.ts:389` `build_token_stats_config` 与 `index.ts:452` `session_history_locator_paths` 的 `win_home: homedir()`(根因注入点,t259 web 端点共用同一 provider/locator);③ `session-locator.ts` `wsl_home()`/`effective_wsl_user()`/`DEFAULT_LOCATOR_PATHS.win_home: homedir()` 及随其同步的 `session-path-index.ts` `paths_key` 签名。其中 session-history 侧为部分分叉:win env 用 `path.join(win_home, ...)` 在 Linux 上恰好解析为本机 POSIX 路径(可用),实际失效面是 wsl env(UNC 在 Linux 内不可达,探测失败返回 null,含仅 wsl 的 grok 会话历史)。
- 根因：产品缺陷(跨平台采集支持缺失),2026-08-11 实证(`.scratch/p132/verify.md`,node 最小复现):`homedir()=/home/karon` 下,collector win 源拼接 `/home/karon\.claude\projects`(反斜杠字面量)exists=false,而 POSIX 路径 `/home/karon/.claude/projects` exists=true;`\\wsl.localhost\Ubuntu-22.04\home` 在 Linux 内 ENOENT。机制链:env 仅 win/wsl 两档无本机维度;`win_home=homedir()` 在 Linux 返回 POSIX home 被当 Windows 宿主 home;wsl 源 `\\wsl.localhost\{distro}\home\{user}`(UNC)Linux 内不可达,`effective_wsl_user` 探测失败返回空串后继续拼出缺用户名坏 UNC(日志实证 `grok_wsl sessions dir missing: \\wsl.localhost\Ubuntu-22.04\home\.grok\sessions`);`read_source` catch 对 ENOENT 静默不记日志。从 8-09 05:36 后持续全 0。
- 测试缺口：`collector.test.ts` mock `win_home: "C:\\Users\\Test"` 全 Windows 风格,path builders 仅 win/wsl 反斜杠输出断言,无 POSIX/Linux 平台用例;`effective_wsl_user` 已有探测空串单点用例(L240),但缺「空串→缺用户名坏 UNC 路径」链路断言;ENOENT 静默分支(`read_source` catch `!msg.includes("ENOENT")`)无测试,采集失败静默空无可见性断言;`collect()` 全 mock reader,无注入 POSIX win_home 读真实 jsonl 集成用例。session-history 侧已有探测失败返回 null 用例(locator L102/L132、path-index f001),缺「Linux 宿主 local 分支读本机 POSIX 路径」显式用例与 `DEFAULT_LOCATOR_PATHS` 默认注入值用例。应补:路径构建按平台注入(homedir/WSL 探测)+ POSIX 用例 + 探测失败显式告警/失败可见性用例,覆盖主位点与已确认同类位点。
