# Task spec

## 背景

用户要求：会话工作台中，**按住会话面板头部的 agent icon 即可拖动整个面板到其它槽位交换位置**。当前面板重排只能透过侧栏槽位列表拖拽，面板本体不可拖。

## 契约区

### 范围

- `SessionPane` 头部 agent icon（`conversation-agent-badge`）作为拖拽手柄：按住拖起面板，拖到目标槽位松开后与目标槽位互换内容（或面板落入目标位，语义与侧栏既有拖拽 `move_slot_ui` 一致）。
- 拖拽过程的可观察反馈：拖拽中的面板有视觉标识，悬停的目标槽位有高亮/占位提示。
- 拖到无效区域松开：面板回到原位，槽位状态不变。
- 重排结果写入同一 slots store，与侧栏槽位顺序保持一致；既有持久化（workspace-storage）随之生效。
- agent icon 单击不产生副作用；拖拽与点击的判定不冲突。

### 非范围

- 不改侧栏槽位列表的既有拖拽行为。
- 不改布局列数/行数计算、不改槽位数据模型字段。
- 不做跨窗口拖拽、不支持拖到空白处新增槽位。

### 风险与回退

- 风险：拖拽实现选型（HTML5 DnD vs pointer 自绘）与既有侧栏拖拽不一致会造成两套手感——实现期优先复用侧栏拖拽的既有方案。
- 风险：拖拽与 t408 的点击展开、t409 删按钮同区域叠加，事件处理冲突——实现期统一梳理头部事件。
- 回退：移除拖拽监听即可，无数据迁移。
