# Task spec

## 背景

用户审查会话窗口发现：面板头部元信息行里会话标题被挤到只剩 4-5 个字符（「capt…」「omni\_…」），而用户真正需要完整看到的 cwd 与时间却被截断或占满整行。用户明确要求：头部必须**完整展示 cwd 和时间**，session id 允许截断；时间格式改为紧凑的 `0817 23:25`（MMDD HH:mm）。此需求推翻已完成 spec `docs/specs/session-pane-display-adjust.md` 的 AC2（目录只显示末级）与 AC4（日期精确到年月日时分秒），需随本 task 修订该 spec。

## 契约区

### 范围

- `SessionPane` 头部元信息：cwd 完整路径直接展示（不再只显示最后一级目录名）；时间/日期字段改为紧凑格式；宽度不足时的截断优先级为 session id 与标题先截断，cwd 与时间保持完整。
- 时间格式规则：当年会话显示 `MMDD HH:mm`（如 `0817 23:25`）；非当年会话加年份前缀 `YYMMDD HH:mm`（如 `2517 23:25` 式的 `250817 23:25`）。
- 修订 `docs/specs/session-pane-display-adjust.md`：AC2、AC4 条目改写为本 task 新语义。

### 非范围

- 不改元信息的数据采集口径（cwd、时间戳来源不变）。
- 不动会话库（SessionLibrary）列表的字段展示；不动头部按钮区与会话标题省略规则本身（仅截断优先级让位于 cwd/时间）。
- 模型、轮次、token 等其它元信息项保留，展示规则不变。
