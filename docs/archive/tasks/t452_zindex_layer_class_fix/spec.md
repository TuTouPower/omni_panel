# Task spec

## 背景

p218 症状C同类并集：裸 `z-*` 层级类（`z-menu/z-sticky/z-scrim/z-context/z-modal`）在 Tailwind v4 下不生成工具类，构建产物零规则，引用点 `z-index:auto`。RangePicker 本体行由 t451 改，本 task 覆盖三同类位点、DESIGN 前提修正与正向门禁。

## 契约区

### 范围

- 三同类位点裸类换可解析层级：`SessionPane.tsx:337 z-sticky`、`SessionPane.tsx:346 z-context`、`SelectionDock.tsx:25 z-sticky`（换 `z-[var(--z-*)]`，数值语义不变）。
- `DESIGN.md` 层级章节修正裸类映射断言（与实现一致）。
- 新增正向门禁捕获同类回归（引用了不存在的工具类即失败）。
- 在 t451 之上复验 RangePicker 弹出层覆盖环图。

### 非范围

- t451 的行为逻辑不动；已正常的 `z-[var(--z-*)]` 引用点不动；阴影/圆角等其它 token 不动。
