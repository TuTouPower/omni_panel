# Task spec

## 背景

p218 主诉之链路三项：web 代理面板时间范围下拉选自定义打不开面板、自定义区间应用不生效（含后台刷新重置编辑、非法区间静默丢弃）、刷新丢失自定义。根因与复现见 `docs/pending/todo/p218_agent_custom_range_broken.md`，最小复现 `.scratch/bug_custom_range/`。

## 契约区

### 范围

- 时间范围下拉选自定义稳定打开 RangePicker（含 custom 已生效后重选可重开；打开期间下拉不再弹回预设）。
- 自定义区间应用链路：合法区间精确生效、非法区间行内报错且面板不关、编辑中途后台刷新不丢输入。
- 自定义区间持久化：刷新后恢复并沿用查询。
- RangePicker 本体 `z-menu` 裸类换可解析层级（与 t452 同类修复在本 task 一并落点，t452 只验不改此行）。

### 非范围

- 会话窗口三同类位点与 DESIGN/门禁（t452）。
- 预设区间语义、gran 规则、查询缓存策略均不动。
