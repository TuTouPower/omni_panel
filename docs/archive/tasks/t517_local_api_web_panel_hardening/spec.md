# Task spec

## 背景

本地 HTTP 服务（LocalAPI）与 Web 端面板（`usageboard-web.ts`）在接口契约、输入校验与前端资源管理方面存在隐患：代理 URL 未做格式校验；JSON 解析存在原型污染风险；CSP 开放了无用的 WebSocket 来源；Web 端网络请求无超时且后台无条件轮询；代理池日志打印明文账密；登出操作在 Web 端假成功；趋势图查询产生多并发 HTTP 风暴。

## 契约区

### 范围

- 校验 `effective_proxy` 输入，仅接受合法的 http/https/socks5 URL。
- LocalAPI 的 JSON 解析增加安全 reviver 过滤危险原型属性；全量审计并保证所有数据库操作使用参数化预编译绑定。
- 收敛 Web 面板 CSP 为 `connect-src 'self'`。
- 日志输出代理信息前对用户名与密码进行脱敏遮罩（如 `***`）。
- Web 端所有 HTTP 请求补充 15s 超时控制；监听 `visibilitychange` 事件在页面隐藏时暂停无谓轮询。
- Web 端重构登出逻辑，真实联动服务端销毁会话与清理订阅，禁止假成功。
- 封装 Web 端查询参数 helper 并规范类型。
- LocalAPI 新增批量趋势查询接口（bulk），Web 面板迁移至批量查询端点。

### 非范围

- 不更改 LocalAPI 免鉴权局域网访问模型（维持现状，见 R7）。
- 不破坏现有 Web 端已有的 SSE 实时推送链路。
