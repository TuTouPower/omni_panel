# Task spec

## 背景

p219 跟进 + 用户需求：custom 生效态单击时间范围下拉，下拉选项列表与自定义日期窗同时弹出（t451 的 click 重开不分“开下拉”与“选中”两次 click）。收敛为单入口：删除下拉框后的「📅 自定义」按钮，只保留下拉框内「自定义」项；click 语义收窄为选中动作才开面板。

## 契约区

### 范围

- 删除 RangePicker 触发按钮（「📅 自定义」），组件改为纯受控面板（唯一调用方 TokenStatsView 已全受控）。
- Select 点击语义区分：`mousedown` 标记开下拉动作（不开面板）vs 无 down 阶段的选中动作（custom 态才开面板）；`change` 逻辑与 t453 失焦关闭不变。
- 旧按钮入口测试整体删除（入口不存在，实施笔记写明理由），面板行为用例改走受控 `open`。

### 非范围

- 面板校验/应用/持久化/层级均不动（t451/t452/t453 已覆盖）。
