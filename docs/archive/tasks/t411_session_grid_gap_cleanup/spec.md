# Task spec

## 背景

用户审查会话窗口截图（框 5/框 6 区域）发现：工作台网格用 `gap-px bg-outline p-px`（`WorkspaceView.tsx:347`）把所有卡片缝成 1px 描线网格，上下两排卡片几乎零距离粘连，行列交汇处四张卡片圆角各自退开露出「四角星」形背景洞，accent 条在交汇处断头。demo（`frontend_demo`）用 `gap-2` 透明间隙，交汇处干净。用户圈出该区域为待修问题。

## 契约区

### 范围

- `WorkspaceView` 的 session-grid：移除 `gap-px bg-[var(--color-outline)] p-px` 描线式网格，改为透明间隙（透出窗口底色），间隙宽度取 `spacing.card-gap` token。
- 卡片保留自身发丝描边与圆角，行列交汇处不再出现星形洞。

### 非范围

- 不改卡片圆角档位、不改列数/行数计算与 `content-start` 布局策略。
- 不改卡片内部结构（头部/消息区/footer 由各自 task 负责）。
