# Task spec

## 背景

用户在三张截图（当前面板 + demo 暗/亮）中都圈出了卡片右缘滚动条区域。当前会话窗口没有定义任何滚动条样式（`src/renderer/styles/globals.css` 无 scrollbar 规则），Chromium 默认滚动条又粗又亮，滚动指示箭头（▲/▼）与滚动条错位，观感像「拇指 + 竖线」两条东西。demo 已有规范配方（`frontend_demo/app/src/index.css:169-189`：6px 细条、透明轨道、token 化 thumb 色 + hover 色）。用户要求会话窗口滚动条统一为该规范样式。

## 契约区

### 范围

- 会话窗口内全部滚动容器：卡片消息区、侧栏槽位列表、会话库列表、大纲列表、摘选托盘。
- 滚动条统一为规范细样式：6px 宽、透明轨道、thumb 颜色取自 token（thumb/hover 两态）；Firefox 侧用 `scrollbar-width: thin` + `scrollbar-color` 等价表达（若项目目标含 web 版）。
- thumb 与卡片滚动指示箭头（▲/▼）同轴对齐，不出现错位双元素。

### 非范围

- 不改滚动行为（滚动跟随、虚拟列表、分页加载）。
- 设置/CPA 窗口的 scrollbar `rgba(120,130,150,...)` 字面量（`SettingsView.tsx:471`、`CpaConnectorSettings.tsx:269/462`）收口为 token 引用。
- 除上述色值收口外，不动其它窗口滚动条的结构性样式；全应用统一留待后续。
- 不新增 token 定义之外的色值；若 token 缺失则在全局 `@theme` 按 DESIGN.md 流程补充，禁止组件内写字面量。
