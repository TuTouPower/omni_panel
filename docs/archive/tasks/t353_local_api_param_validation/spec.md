# Task spec

## 背景

local-api 多个读端点（`/v1/records`、`/v1/heatmap`、`/v1/hourBuckets`、`/v1/rollup`、`/v1/sessions`、`/v1/buckets`、`/v1/sessionHistory`）用 `Number(params.get(...))` 直接构造 SQL filters，非数字输入产生 NaN 直入 SQL，无 isFinite 校验。同族 `/v1/dashboard` 走 zod 返回 400，这些端点却静默空结果或 500。非法输入应统一 400 而非 500。

## 契约区

### 范围

- 抽共享 `parse_int_param`（isFinite + 非负校验）或对这些端点统一加 zod query 校验。
- `/v1/sessionHistory` 的 limit 加 `> 0` 下限校验。
- 非法输入统一返回 400。

### 非范围

- 不改查询语义/字段。
