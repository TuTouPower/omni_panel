# Task spec

## 背景

会话库网格/列表无限滚动（t328）的挂载 effect 仅在「首屏不溢出」时主动加载一页填满。极端场景：视口极大（~3900px 高）时自动加载第 2 页后仍不溢出，不会再次触发加载，列表停留不足一屏。p146 登记（t328 遗留 minor）。修复：挂载后循环补满至溢出或 has_more=false。

## 契约区

### 范围

- `src/renderer/components/session-library/SessionList.tsx`：挂载 effect 改为「补满循环」——首屏不溢出时主动加载，加载后若仍不溢出继续加载，直到溢出或父 `load_more` 的 has_more=false 终止。
- 保持 t328 的滚动触底加载、has_more/inflight 守卫不变。

### 非范围

- 不改滚动触底加载逻辑、has_more/inflight 守卫、分页接口。
- 不改卡片尺寸/内容。
- 不做虚拟滚动。
