# Task spec

## 背景

本地连接器无界/全量重扫：(1) codex 连接器每轮刷新对两个会话目录全量 list + 逐个 read + 逐行 JSON.parse，无增量无缓存，每 5 分钟全量重扫；(2) 本地脚本对会话目录整树无界读取，无扩展名/大小过滤、无并发限制。

## 契约区

### 范围

- codex 连接器按文件 mtime/size 增量处理（维护每文件解析 offset 或只读新增行），或按 size 上限跳过超大文件、限定扩展名。

### 非范围

- 不改 codex 会话解析语义。
