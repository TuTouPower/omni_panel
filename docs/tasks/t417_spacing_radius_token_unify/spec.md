# Task spec

## 背景

DESIGN.md 合规审计（2026-08-16）发现布局间距与圆角大量偏离基网/档位：布局层 `p-*`/`gap-*`/`m-*` 出现非 4px 倍数值数十处（0.5 步进 2px、`gap-1.5`=6px、`2.5`=10px、3/5/7/11/13/15/22px 等，集中于表单区、CpaConnectorSettings、ProviderNav、session 体系）；圆角六档（6/8/10/14/18/999）之外有 `rounded-[9px]`/`[7px]`/`[4px]` 约 6 处。DESIGN.md 规定「布局层的 p-*/gap-*/m-\* 直接用整数倍」「圆角尺度收敛为六档」。

## 契约区

### 范围

- 布局层间距归位：非 4px 倍数的 `p-*`/`gap-*`/`m-*`（含 arbitrary 值与 0.5 步进）归位到 4px 基网或语义 token（card-gap/card-padding/section-gap/panel-padding/row-height）。
- 圆角归档：7/9/4px 等 arbitrary 圆角归位到就近六档。
- 逐点映射记录在实施笔记；组件 token 定义值（按钮 9/18、输入框 9/12、列表行 10/12）与语义 token 值（12/14/16/24）属豁免，不算违规。

### 非范围

- 不改 token 数值定义；不改组件结构。
- 内容卡片圆角已全部合规（lg/14px），不动。
- canvas 图表 borderRadius（Heatmap 3px）随本 task 就近归档或记录为例外。
