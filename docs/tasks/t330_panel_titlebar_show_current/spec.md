# Task spec

## 背景

面板右上角切换按钮区（`PanelTitleBar` 面板形态）当前用 `.filter((p) => p !== panel)` 隐藏当前面板的按钮。用户要求取消该机制：当前面板按钮也显示，四个面板按钮（Usage/Agent/Session/Settings）恒定呈现。

## 契约区

### 范围

- `src/renderer/components/ui/PanelTitleBar.tsx` 面板形态切换按钮区：移除 `.filter((p) => p !== panel)`，四个面板按钮恒定渲染（含当前面板）。
- 当前面板按钮点击行为：点击自身面板按钮不产生错误（navigate 到自身幂等或等价处理，以现有 onNavigate 行为为准）。
- 同步更新受影响的组件测试（PanelTitleBar 按钮渲染/顺序断言）。

### 非范围

- 不改按钮顺序（t313 固定序「设置 用量 代理 会话」保持）。
- 不改 popup TitleBar / TokenStatsView 的互跳按钮（无此隐藏机制）。
- 不改 icon/样式/路由。
