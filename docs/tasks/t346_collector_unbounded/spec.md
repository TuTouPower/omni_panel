# Task spec

## 背景

collector 有两处无界增长：(1) `emitted_record_keys` 内存 Set 对每条已发射记录入集合，常驻内存随历史消息总量线性增长（可达数十至数百 MB）；(2) `scan-state` 每轮 collect 无条件全量序列化并 fsync 写盘，即使本轮无新数据也完整重写，state 文件随历史 jsonl 文件数增长。

## 契约区

### 范围

- `emitted_record_keys` 按时间窗裁剪（只保留近 N 天的 message_id 去重），或把去重状态纳入 scan-state 持久化并限制条数。
- `scan-state` 保存跟踪 dirty 标志，无新数据跳过保存，或节流（至多每 10 分钟一次）。

### 非范围

- 不改增量正确性逻辑（见 t345）。
