# Task spec

## 背景

用户审查会话窗口截图发现两处窗口 chrome 问题（框 1/框 2）：

1. 顶部 `session-rail-toggle-row`（`SessionShell.tsx:107`）整行约 75px 高，却只有最左一个「«」折叠按钮，其余 2600px 全空，白占一整行。
2. 侧栏「+ 添加会话」按钮紧跟列表末尾，其下大片空白。用户拍板：恢复侧栏**底部固定**「添加会话」按钮，且侧栏折叠时该按钮退化为加号 icon。这推翻已完成 spec `docs/specs/session-pane-display-adjust.md` 的 AC7（侧边栏底部不再有添加会话按钮），需随本 task 修订。

两处同属会话窗口框架 chrome 的布局对齐（参照 demo `SessionRail`：头部行内含槽位计数与折叠钮，底部固定添加按钮），作为一个 task 交付。

## 契约区

### 范围

- `SessionShell`：删除独立的 `session-rail-toggle-row` 整行；「«/»」折叠按钮挪入 `SessionRail` 头部行内（与槽位计数同行）。
- `SessionRail`：底部恢复固定「添加会话」按钮（border-top 分隔、不随列表滚动）；展开态为全宽文字按钮，折叠态退化为加号 icon 按钮。
- 修订 `docs/specs/session-pane-display-adjust.md`：AC7 改写为底部固定按钮 + 折叠态加号的新语义。

### 非范围

- 不动页签栏（工作区/会话库切换）与窗口标题栏。
- 不动摘选托盘、侧栏槽位列表项结构与拖拽。
- 折叠态侧栏头部既有加号入口与底部加号并存关系由实现期收敛（同一动作不保留两个重复入口）。
