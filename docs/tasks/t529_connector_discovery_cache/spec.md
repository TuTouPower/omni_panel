# Task spec

## 背景

p263 中 Muse 每轮刷新（30s 调度周期）与每次失败重试都重新执行动态发现，串行下载 100+ 分包，既打满预算又持续压站。根因之一是连接器运行在隔离子进程内，没有持久化能力：成功解析出的 Action ID / 部署标识只存在于单次执行内存，无法跨刷新复用。

本 task 为连接器提供**类型化的发现结果缓存**（`ctx.discovery`），宿主定 schema，连接器只填业务键。依审阅结论（A/B/C）：它不是通用状态数据库、不是无限制 KV，而是可丢弃的发现数据；缓存丢失或损坏只增加发现成本，不改变采集正确性。命名空间含代码 hash，脚本升级即自动失效；协议为破坏性升级，主进程与 worker 同步演进，不保留新旧兼容。

## 契约区

### 范围

- 类型化发现缓存 `ctx.discovery`：宿主定义记录 schema `{signature, action_id, deployment_id, discovered_at, hits}` 与格式版本；连接器只提供业务键与记录值。
- 命名空间 = `manifest_id:instance_id:code_hash`：连接器脚本升级（code hash 变化）自动隔离旧缓存，不误命中。
- 隔离协议：worker 任务载荷下发缓存快照；执行结果回传导出的写回 delta（带 generation）；合并点唯一在宿主。
- generation 语义：超时 / 崩溃丢本轮 delta、保留旧记录；过期执行 generation 的写回不得复活或覆盖较新的记录。
- 容量治理：条目数上限 + 总字节上限 + 单 value 上限；LRU 逐出；miss 重发现仍成功，淘汰只影响命中率。
- 持久化：dataRoot 下独立 `connector-cache.json`，原子写 + fsync；文件损坏丢弃重建；与 config / observations 隔离。
- 降级：读 / 写失败不失败采集，退化为内存缓存并产生结构化告警。
- secret 强制拒绝：key 命中 secret 名或 value 命中 vault 值即拒写 + warn，不落盘、不落日志（硬判据，非文档约定）。
- 破坏性协议升级：主进程与 worker 同步升级，版本不匹配明确失败；缓存带独立格式版本，不兼容即丢弃重建。

### 非范围

- 不做通用状态数据库 / 任意用途 KV。
- 不实现具体连接器的键与失效策略（t530 掌握 Muse 逻辑）。
- 不引入执行预算 / 协作取消（t528）。
- 不改变观测存储（observation-store）语义。

- [ ] AC-001：连接器执行后可写入发现记录；同一实例的后续刷新能读到该记录，含 signature / action_id / deployment_id / discovered_at / hits。

- [ ] AC-004：连接器执行超时 / 崩溃时，本轮未回传的 delta 不破坏已持久化记录，旧记录保持可读。
- [ ] AC-005：签名变化时连接器可覆盖既有记录；覆盖后读到新值。
- [ ] AC-006：容量（条目数 / 总字节 / 单 value）超限时按 LRU 收敛；淘汰不改变采集正确性，miss 重发现仍成功。
- [ ] AC-007：持久化读 / 写失败时采集仍成功返回，降级为内存缓存并产生结构化告警。
- [ ] AC-008：secret 强制拒绝：写入 key 命中 secret 名或 value 命中 vault 值时拒写并告警，不落盘、不落日志（以落盘文件与日志均不含该值断言）。
- [ ] AC-009：连接器脚本代码 hash 变化（升级）时，旧命名空间记录不被命中。
- [ ] AC-010：缓存文件损坏时被丢弃重建，采集不受影响。
- [ ] AC-011：同实例并发 / 过期执行携带旧 generation 的写回，不得复活或覆盖较新记录。

## 上下文区

- 来源：p263（核实 2026-09-27：发现结果每次刷新 / 重试重算，无跨刷新复用；隔离 worker 无持久化通道）；审阅意见 A/B/C（类型化发现缓存、命名空间含 code hash、secret 强制拒绝、删协议兼容）。

### 有意不测

- 缓存的业务键设计质量：属各连接器（t530）。
- 多实例并发写同一命名空间的合并：每实例命名空间写者唯一（同实例刷新有锁 + generation），不做并发合并测试。

### 测试策略

- 单测：类型化读写、命名空间隔离（含 code hash）、LRU 与三重容量上限、覆盖、原子落盘与重启保留、损坏丢弃、读写失败降级、secret 拒写。
- 集成：经隔离宿主跑消费 `ctx.discovery` 的测试连接器，断言快照下发、写回合并、超时丢 delta 保旧值、过期 generation 不覆盖。
- 回归：现有连接器测试保持通过（不消费 `ctx.discovery` 者业务不变）。

### 风险与回退

- 风险：协议破坏性升级要求主进程与 worker 同版本；若打包产物与新协议不一致会明确失败（符合预期，不静默降级）。
- 回退：不设运行时降级开关；失败即 git revert。缓存为可再生数据，格式不兼容直接丢弃重建，不维护长期兼容层。

### 依赖与约束

- 前置：t528（宿主核心与隔离协议面，串行以避免重叠改动）。
- 约束：缓存不得成为 secret 存储（secret 仍走 vault）；持久化失败不得影响采集；写盘须原子；缓存定位为可丢弃发现数据，不得承载未来通用状态。
- 平台：Windows / macOS / Linux 一致（dataRoot 定位复用现有实现）。
