# Task spec

## 背景

用户审查会话窗口（截图框 7）指出两处消息行问题：每条消息被裁成单行后挂一个裸蓝色「展开」文字按钮，满屏「展开」；且用户消息与 Agent 消息视觉上无区分。用户要求：用户消息加背景色突出（拍板用 `primary-container`）；**去掉「展开」按钮**，用户消息与 Agent 消息统一改为「点一下消息本体展开、再点一下收回」。此需求推翻已完成 spec `docs/specs/session-pane-display-adjust.md` 的 AC9/AC10（超行消息显示展开按钮、点击按钮切换），需随本 task 修订。

## 契约区

### 范围

- `PaneMessageRow`：移除「展开」「收起」按钮；点击消息本体区域在「完整内容」与「单行折叠」之间切换；仅单行的消息无折叠态（点击无折叠效果）。
- 用户消息（role=user）整行铺 `primary-container` 背景色突出；Agent 消息保持无底。
- 点击行首 checkbox 只切换选中态，不触发展开/收起切换；在消息文本上拖选（产生文本选区）不触发切换。
- 修订 `docs/specs/session-pane-display-adjust.md`：AC9、AC10 改写为点击消息本体切换的新语义。

### 非范围

- 不改 Markdown 渲染、消息数据链路、摘选/多选数据流。
- 不改单行折叠的默认态（消息仍默认单行折叠，只是切换入口从按钮改为点消息本体）。
- Agent 消息不加底色；不动消息 meta 行（角色/时间）内容。
