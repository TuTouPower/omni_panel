# Task spec

## 背景

用量面板多账号 provider 卡片头部的「概览 / N账号」分段 tab，选中态样式共用同一个 `l2Open` 布尔：概览态（l2Open=false）两个 tab 都无强调，明细态（l2Open=true）两个 tab 都白底蓝字高亮。用户无法区分当前视图。根因见 p134。

## 契约区

### 范围

- 修复 `ProviderCard.tsx` 概览/N账号两个 tab 的选中态：当前激活 tab 有强调样式，非激活 tab 无强调样式（互斥）。
- 同步更新/新增组件测试覆盖两种选中态。

### 非范围

- 不改 tab 行为语义（l2Open 仍表示「是否展开账号明细」）。
- 不做 tab 之外的重设计。
