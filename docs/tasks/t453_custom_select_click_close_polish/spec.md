# Task spec

## 背景

t451 让自定义态单击时间范围下拉即可重开面板（原生 select 同值不发 change，只能靠 click）。副作用（p219）：用户本想切预设却以点外部/Esc 取消选择时，面板多余滞留。本 task 收窄：click 打开后若无 change 收场（失焦），自动关闭。

## 契约区

### 范围

- click 重开后面板行为：无 change 而失焦 → 自动关闭；有 change（选预设/选 custom）→ 走既有逻辑。
- 回归锁：t451 AC-001/002/003 行为不变。

### 非范围

- 预设/custom 应用链路、持久化、层级均不动（t451/t452 已覆盖）。
