# Task spec

## 背景

会话面板中「最近会话 / 清空 / 视图」三按钮当前渲染在 WorkspaceView 次级 topbar（`session-workspace-topbar` 行内），与主窗口顶栏（共用 PanelTitleBar，含刷新按钮）分属两行。用户实看截图确认：三按钮应上移至顶栏、置于刷新按钮左侧，消除次级 topbar 行；且 t318 收尾后卡片上方仍残留一行空白（截图可见工具栏下沿与卡片信息栏之间有一条暗色空带）。

## 契约区

### 范围

- 将「最近会话 / 清空 / 视图」三按钮从 WorkspaceView 次级 topbar 上移至顶栏，渲染在刷新按钮左侧，顺序保持 最近会话 → 清空 → 视图。
- 移除因按钮上移而空置的次级 topbar 结构（或合并进顶栏行），消除卡片区域上方残留空行。
- 保留 rail-toggle 折叠功能与布局基线。

### 非范围

- 不改三按钮的功能与交互（弹窗、清空、视图下拉内容）。
- 不改会话卡片信息栏内容（属 t324）。
- 不改其他面板（Usage/Agent/Settings）顶栏结构。

### 风险与回退

- 风险：PanelTitleBar 为四面板共用组件，上移按钮可能影响其他面板顶栏布局；需用面板形态插槽隔离，确保其他面板不渲染会话按钮。
- 回退：改动集中于顶栏渲染与次级 topbar 移除，撤销提交即恢复原两行结构。
