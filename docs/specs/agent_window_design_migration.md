# agent_window_design_migration

Agent 统计窗口使用统一设计系统组件与语义 token，内容区与面板标题栏共享色板、字体与主题方向。

## 设计范围

- KPI、图表、表格、时间范围筛选、徽章和品牌标识使用共享 `ui/*` 组件与语义 token。
- 现有统计信息结构、图表类型、表格列、徽章种类和筛选行为保持不变。
- 窗口不再维护独立色板、字体栈或专属样式作用域。

## 交互与展示

- KPI 数值、图表切换、表格分页、时间范围筛选和会话打开行为保持可用。
- 主题和强调色由全局设置控制，窗口内容区与标题栏使用同一强调色及派生状态色。
- 明暗主题切换不依赖窗口专属主题分支，默认方向与全局主题一致。

## 图表配色

- ECharts 图表通过语义 token resolver 在渲染期解析轴、提示框、类目、dataZoom 和热力图等颜色。
- 主题或强调色变化会使图表 palette revision 递增并触发 option 重绘；已绘制 canvas 内容不依赖 CSS 类自动更新。
- resolver 在无法读取运行时 token 时使用稳定的主题回退色板，保证图表仍可渲染。

## 样式约束

- 颜色、背景、边框、焦点环、状态和字体通过语义 token 表达。
- token-stats 专属样式文件、变量和类名不保留引用。
- 内容区与窗口外壳使用同一字体栈、色板和主题语义。

## 验证

- Web 使用 Chromium 验证面板导航和内容渲染。
- Desktop 使用真实 Electron 验证窗口创建、标题栏、内容加载、关闭和快捷键行为。
- 单元测试验证 token resolver 的实际颜色解析、主题与强调色通知、palette revision 和 ECharts 重绘触发。
- 视觉符合 DESIGN.md 属人工验收，自动化测试不替代逐屏对照。
