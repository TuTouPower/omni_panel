# session_window_design_migration

会话历史窗口统一使用设计系统组件与语义 token。工作台、会话库、预览、摘选 dock 与会话面板共享全局色板、字体、主题方向和强调色。

## 设计范围

- 会话列表、搜索、摘要、工作台网格、预览、dock 与消息面板使用共享 `ui/*` 控件和语义 utility。
- 列表加载与懒加载、内容搜索、摘要展示、布局切换与拖拽、预览、会话选择、摘选复制和消息展示结构保持不变。
- 会话面板消费可达数据源的 agent 识别色：Claude、Grok、OpenCode、Kimi；未知来源使用稳定 fallback。
- 窗口不维护独立色板、字体栈、暗色默认方向或专属样式作用域。

## 交互与展示

- 会话窗口由工作台与会话库两个页签组成，页签切换不丢失已打开槽位和摘选状态。
- 会话库支持标题、路径、会话 ID 与消息内容搜索，日期与 agent 筛选，排序、分页加载、卡片/列表视图、预览和批量打开。
- 消息内容搜索（t404）：候选分块 + 进度「已扫描 N/M」+ 增量结果合并；取消中止未完成分块。详见 `session_content_search_cold_perf.md`。
- 工作台支持槽位布局、面板关闭、消息选择、摘选托盘、消息展开/折叠、大纲定位和向上分页（t409 移除面板聚焦与头部全选/清空选择入口）。
- 主题跟随全局配置；强调色跟随全局强调色设置，即时影响窗口标题栏、控件状态、焦点环和交互反馈。

## 样式约束

- 颜色、背景、边框、焦点环、状态和字体通过语义 token 表达。
- 会话窗口独立样式文件、旧色板变量、旧字体栈和旧 token 桥接不保留引用。
- 组件代码不增加窗口专属 `dark:` 分支；明暗值由全局语义 token 提供。
- agent 识别色在明暗主题下均从统一 token 读取，未知来源回退到 primary 语义色。
- 背景两级（t406）：壳/侧栏/主区 `surface-window`；会话 pane 与会话库卡/行 `surface-card`；`surface-raised` 仅 hover/分段/徽章等交互态。详见 [`surface_token_unify.md`](surface_token_unify.md)。

## 验证

- Web SPA 使用 Chromium 验证页签切换、会话打开、消息渲染、选择复制、搜索筛选、预览和虚拟列表行为。
- Desktop 使用真实 Electron 验证窗口相关行为；无头环境下隐藏窗口，不以可见窗口作为自动化测试前提。
- 单元测试覆盖会话窗口组件、消息滚动、布局状态、选择托盘和语义字号断言。
- 静态检查确认独立样式文件、旧变量、旧 import 和旧样式类引用均已清理。
- 视觉符合 DESIGN.md 属人工验收，自动化测试不替代逐屏对照。
